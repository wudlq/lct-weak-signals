# Сертификаты

Здесь лежит `russian_trusted_ca.pem` — публичный корневой сертификат НУЦ
Минцифры. Он нужен только для обращений к GigaChat: домены Сбера
(`ngw.devices.sberbank.ru`, `gigachat.devices.sberbank.ru`) подписаны им, а в
системном хранилище и в пакете `certifi` его нет, поэтому без сертификата
запрос падает с `CERTIFICATE_VERIFY_FAILED`.

Если файла нет, соберите его:

```bash
bash scripts/install_ru_certs.sh
```

Проверить, что TLS до Сбера проходит:

```bash
python -m src.texts.certs
```

Проверка TLS в проекте нигде не отключается. Сертификат добавляется в доверенные
вместе с обычным бандлом `certifi` — файл `_bundle.pem` собирается на месте и в
репозиторий не попадает.
