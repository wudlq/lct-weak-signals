# Горизонт — сервис поиска слабых технологических сигналов

Кейс Газпромбанк.Тех, ЛЦТ 2026. Команда negentropy.

Сервис принимает запрос по технологическому направлению в свободной форме,
собирает документы из открытых источников, отделяет зарождающиеся технологии
от зрелых решений, отраслевых стандартов, маркетингового хайпа и
информационного шума, и формирует ранжированную выдачу с обоснованием
по каждому сигналу.

---

## Быстрый старт через Docker

Единственное требование — установленный Docker.

```bash
git clone <адрес-репозитория>
cd <папка-репозитория>
docker compose up --build
```

Приложение откроется на **http://localhost:8501**

Остановить:

```bash
docker compose down
```

### Ключ языковой модели (необязательно)

Без ключа сервис работает: резюме источников строится извлечением
предложений из текста документа, и в выдаче это помечено. С ключом
резюме генерируется.

Создайте файл `.env` рядом с `docker-compose.yml`:

```
LLM_PROVIDER=gigachat
LLM_API_KEY=ваш-ключ
```

Допустимые значения `LLM_PROVIDER`: `gigachat`, `yandexgpt`, `qwen`, `openai`, `none`.
Список моделей ограничен техническим заданием; сторонние сервисы-посредники
не используются.

```bash

```

Скрипт обучает модель на датасете организаторов и негативном классе,
печатает Precision, Recall, F1 по пятикратной кросс-валидации, веса

## Как система решает, что перед ней слабый сигнал

Модель опирается на тринадцать интерпретируемых признаков, а не на скрытое
представление текста. Основные:

| Признак | В какую сторону работает |
|---|---|
| динамика упоминаний | быстрый рост при малой базе — за сигнал |
| маркеры ранней стадии | seed-раунды, выход из stealth, препринты — за сигнал |
| число независимых игроков | два-четыре — за сигнал, десятки — против |
| возраст темы | первые упоминания за последние два года — за сигнал |
| маркеры зрелости | утверждённый стандарт, доля рынка, IPO — против |
| маркеры хайпа | опора на пресс-релизы, превосходная лексика — против |

Логистическая регрессия выбрана намеренно: её веса читаются напрямую,
поэтому по каждому наблюдению система показывает, какие именно признаки
привели к решению. На тех же признаках без текстовых эмбеддингов качество
не падает — методология, а не текстовая «магия».

Подробнее — в файле `ОТЧЁТ_О_МОДЕЛИ.md`.

## Доверенность источников

Каждый источник получает один из трёх уровней: высокий (наука, госорганы,
международные организации, университеты, отраслевые ассоциации), средний
(профессиональные отраслевые медиа, аналитические агентства, официальные
сайты компаний-разработчиков) и низкий (пресс-релизные сети, агрегаторы,
каталоги стартапов, соцсети).

Источник низкого уровня не может быть единственным основанием для включения
технологии в выдачу. Отдельно ведётся чёрный список изданий, которые
не используются вовсе.

По каждому источнику в интерфейсе отображаются наименование, ссылка, дата
публикации, тип, язык оригинала и уровень доверенности. Для зарубежных
материалов даётся русскоязычное резюме с пометкой о способе его получения.

## Известные ограничения

Названы честно, поскольку влияют на интерпретацию метрик.

1. **Негативный класс составлен вручную.** Из-за этого он отделяется от
   позитивного легче, чем реальные данные, и метрики на нашей выборке
   завышены относительно закрытого датасета организаторов.
2. **Источники ограничены научными базами.** Патентные базы в текущей
   версии не подключены.
3. **Отсутствие источников высокого уровня не ведёт к отсеву.** По ранним
   темам научных публикаций часто ещё нет; такие наблюдения получают
   пониженную уверенность, а не исключение из выдачи.
